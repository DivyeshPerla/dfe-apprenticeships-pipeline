What it is

UK government statistics: a free API, seventeen tidy columns, fifty thousand rows. Profiling it before writing any pipeline code turned up four defects, none visible in the schema. 80% of rows are subtotals mixed in with the detail, so a plain SUM counts the same records once per subtotal they appear in.

The pipeline handles all four, proves it with tests on every run, and verifies its own compliance posture against live cloud state.
